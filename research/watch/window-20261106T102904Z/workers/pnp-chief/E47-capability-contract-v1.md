# E47：以能力保全和现实覆盖替代200B（v1）

分类：定义候选及条件定理；不是现实覆盖已经通过。作者chief也作为节点研究员，原标准P/NP仍未解。

## 1. 收缩对象是可执行系统，不是参数数目

定义A_θ为同一输入/交互协议下的统一可执行程序，满足可强制执行的代码、时间、工作存储、输入访问/I/O、通信和工具资源包络θ。原语及预算单位事先固定，程序和编译产物在测试实例前固定。

θ必须是数值/尺寸函数和可核对计费规则，而非只说“多项式”或容许任意巨常数。只读输入、模型权重、工作内存、外部数据、可回读输出与工具状态分别记账。现实工具可作为系统内受计费组件，不是免费答案oracle；定义工具权限不等于擅自取得实际服务/凭据权限。

能力底线不宜随便禁止重读材料、检索、普通计算、存储与合理组合。若新模型恢复这些能力，旧单遍INDEX下界就必须重审，不能把旧证明直接贴上新类。

限制本身应是结构/资源条件，不许用“能解现实问题”作为成员资格，否则是在定义中预埋结论。

## 2. 用统一解法组合定能力下限

以架构无关的参考解法组合B及其可执行路由ρ为下限：包括通常数值/符号计算、数据处理/检索、程序执行、规划/交互及必要的学习组件。具体模块、适用域、失败方式与资源待后续节点列证据，不在此断言该目录已经覆盖现实。

ρ与B冻结成一个实际策略B_*，根据可观察输入/历史选算法；ρ自身代码、计算和失败也计费。不能用评测真值、未来不可见信息、外部正确答案选择器挑一个刚好会回答的算法。

能力保全证书要求一个统一、有效、答案无关的编译/模拟C，使C(B_*)属于A_θ，并在已声明的资源开销及行为误差内模拟B_*。编译期、启动期、元数据、工具成本都不能免费。条件保证可比“200B”更明确，但仍只有相对于B_*的能力保全。

## 3. 必须排除错误量词

∀测试实例e，∃某程序P_e正确，远弱于∃一个预先冻结的策略P，在现实分布上高成功率。前者允许硬编码每题答案，任何有限评测都会变得空洞。

反例：两个等概率episode的全部可观察信息相同，正确标签分别0与1。类里有常数0和常数1两个程序。事后按真值挑程序得100%，任何实际可观察路由最多50%。这里不是声称现实任务都不可识别，而是证明把事后最佳算法当可执行路由会错。

对真正的问题族可以按族使用不同程序，但族标识/任务描述必须可观察，选择规则须统一且在实例答案之前确定。程序描述预算也不能允许按实例携带答案表。

## 4. “绝大部分”的双轴定义

不能按所有可编码题目的个数计比例；可任意复制/重命名改变分母。采用外部来源、事先冻结的现实episode分布μ，并同时规定领域集合、权重与领域内能力底线。

主指标是任务频率/重要性加权的成功率；每领域还须有预定下限，防止总体95%掩盖整个重要领域失败。若用户想衡量问题族而非episode，需要分层抽样及族内成功率估计，不能把episode成功率冒充问题族覆盖率。

成功必须包含正确/合格结果、允许的交互、资源与时限；资源耗尽或非法工具调用是失败，不删出分母。阈值如95%只是可讨论的操作目标，未被测量、不能在此宣布达标。

## 5. 一个可复核的条件覆盖下界

设冻结B_*在独立评测分布ν的N个IID episode上观测平均loss为r_hat，loss在[0,1]。给定失败置信α，Hoeffding给出概率至少1−α的

r_ν(B_*) ≤ r_hat + sqrt(log(1/α)/(2N))。

如果事先有TV(μ,ν)≤Δ的依据，C的平均行为耦合误差≤ε，超预算/执行失败概率≤β，评测与真实loss差≤ξ，则同一置信事件上：

r_μ(C(B_*)) ≤ min(1, r_hat + sqrt(log(1/α)/(2N)) + Δ + ε + β + ξ)。

证明：bounded loss下分布转移最多Δ；耦合不一致最多ε；执行失败按loss1付β；评测差付ξ，逐项三角/union界。ε若仅对执行成功条件成立，β必须单列，不能混成一个无依据的误差项。

该不等式是条件保证，不是新数据。Δ/β/ξ未知时保持未知，不能默认为0。重复同一问题族的相关prompt不能当独立N；事后从K个模型中挑最好，至少要用独立holdout或相应选择修正（固定K可用log(K/α) union界），不能偷用单模型界。

各领域分别做估计并分配置信预算α_d，总体置信由Σα_d控制。数值coverage阈值与统计置信度是不同量，也不是调度器的启发式Q。

## 6. 为什么单个benchmark不能“保证现实”

若不限制现实分布与评测分布的关系，有限bench外的分布可把质量全压在未覆盖输入上。因此bench通过不蕴含开放现实世界覆盖。需要现实采样来源、领域代表性、漂移/缺失质量与风险口径的独立证据。

能严格保证的是：(a) 已声明协议/预算下的统一能力保全；(b) 已声明分布及统计假设下的覆盖下界。二者合起来才是可验收的“足够强”；不能把后半部分写成定义就算证明。

## 7. 与分离目标的关系

下一步必须为同一个A_θ及其计费协议证明严格分离，不能从弱模型转移旧见证而不检查假设。证书/验证器长度、计算和空间按原始任务预算计费，不能靠免费长证书或免费外部机器造分离。

若要求A同时保全所有P算法且模拟开销仍多项式、A又⊆P，就退化为A=P；若相应NP_A也等标准NP，分离又是标准P/NP问题。现实分布覆盖并不等于包含所有P，应避免无意把“足够现实”升级成这条强要求。
