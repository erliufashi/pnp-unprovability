# 三层单向研究网络 0.1

## 分层与正交性

- 第1层（4个方向）：D1自指/可证性；D2算术见证/增长率；D3资源预算/精确相消；D4模型/反例审计。各自不以其他方向的未证判断为事实。
- 第2层（7个工具/里程碑）：M1门控NP编译器；M2反思判别器；M3反例总性正规形；M4预算审计器；M5模型转移检查；M6主目标桥接义务；M7不可证性到算法路线。
- 第3层（14个初始叶节点）：每个是可单独查验的推导或源文献核验，有明确产物与局部验收，不要求解决总目标。

逻辑依赖只允许3→2、2→1，允许一项证据支撑多个工具，所以不是单纯的树。禁止同层、跨层、反向依赖。若后续工具产生新的实验问题，创建一个新节点/新图谱版本，不把信息反馈伪装成依赖环。顶层goal是行政总目标，不是研究网络的第四层。

## 参数与邻接传播

所有0..1量是人工有依据的估值，不是统计概率：

- C：当前价值，完成当前可检验操作的收益。
- R：预期剩余价值，该节点未探索部分的收益；耗尽必须为0。
- N：概念/证据新颖度；同一失败重试不能设高。
- Q：当前操作能产生可信信息的置信权重，不是解决P/NP的概率。
- K>0：相对剩余成本。
- s：连续无增益次数；a：距离上次实际研究的轮数；h：相邻节点中出现尚未消化的新revision的比例。

对无向邻接集合N(i)计算派生量（不改变依赖箭头）：

Ceff(i)=0.8 C(i)+0.2 mean(C(j),j∈N(i))
Reff(i)=0.8 R(i)+0.2 mean(R(j),j∈N(i))
F(i)=0.65 N(i)·2^(-s/3)+0.20 min(a/6,1)+0.15 h
Priority(i)=Q(i)·[0.45 Ceff(i)+0.35 Reff(i)+0.20 F(i)]/K(i)

上式中的N(i)在F公式表示本节点novelty，在邻接均值公式表示邻居集合；CLI字段分别为novelty和neighbors，避免实现歧义。终结节点在传播时C=R=0，自身priority=0。只有第三层ready、R>0、且至少一个直接上层仍开放的节点可选。blocked/done/exhausted不被闲置时间或邻居信号自动复活。并列按ID稳定选择。

每次update记录原始参数变化、证据路径及SHA256、依据；直接邻居的有效价值/余值及新鲜度因此变化。参数变化后立即重选。worked记录实际研究并消化当时邻居revision；无增益时新鲜度衰减。done表示局部验收完成，不能自动把上层定理或总目标判成已证明。上层状态与R须依据实际证据人工更新。

## 事件规则

1. 初始、每次update、节点耗尽、显式上下文恢复、证据改变时刷新。
2. 看到压缩摘要就执行refresh --reason context-resume；这是恢复协议，不是自动Pi hook。
3. 执行当前推荐叶节点一个可验动作；记录定理/反例/准确缺口后更新，不按机械轮数假造进展。
4. 节点耗尽必须给证据、R=0，刷新立刻选择其他分支。重新开启必须有新证据和明确不同于失败模板的新操作。
5. 没有可选节点时返回selected=null，列明待证义务；不得将调度器循环当研究。

## 持久化、owner与界限

唯一writer是当前主研究代理/用户的CLI操作，fcntl非阻塞锁排斥并发writer。state.json原子写入，是权威状态；其events是权威历史，history.jsonl是可重建投影。读者不写状态。图谱摘要变更会拒绝旧状态，必须显式迁移并保留旧版本；0.1不提供静默迁移。

参数评分只用于找下一个有信息量的工作，不是完备证明搜索；完成图谱不蕴含解决开放问题。有限实验、Python测试和文献屏障都不承担ZFC不可证性证明。
