# T3：单遍对数空间中的渐近分离

状态：完整数学论证，待独立审查；未做证明助手全形式化。该定理不是标准P≠NP，也不是标准命题的不可证性。

## 1. 同一个受限模型M

输入为有限字母表上的长度n字符串，有一个只能向右移动的只读输入头，可停留做内部计算但不能回读已越过的符号。输入结束有明确EOF。没有可回读输出、外部工作带、工具服务或未计费的输入相关时钟/地址。工作带可读写，全部输入相关的持久寄存器、控制状态、位置计数和随机源状态计入空间；固定程序是只读常量。判定答案只在EOF后输出。

每台算法有固定有限程序、固定常数c,d，所有输入上使用至多c log2(n+2)个工作位、至多(n+2)^d乘固定常数的步骤。固定控制开销可并入c；不允许通过对常数逐点卡预算制造分离。

P_M：这样确定性判定的语言。
NP_M：同一输入/工作空间/多项式时间模型的非确定性版本；每条计算分支都满足资源界，存在接受分支即接受。无外部SAT或真假oracle。

P_M⊆NP_M显然。这里的限制在对所有常数c,d取并集后仍有效，是单遍输入及对数空间的渐近限制，不是固定状态数差一位的伪P/NP分离。

## 2. 精确定义INDEX

对m≥1，令ℓ(m)=floor(log2 m)+1。定义：

INDEX = { x#z : x∈{0,1}^m，z恰有ℓ(m)位，1≤val(z)≤m，且x[val(z)]=1 }。

索引从1开始。允许z有前导0以填满固定宽度。空x、缺失/多个#、不合法符号、索引长度不符、索引为0或大于m，一律拒绝。对固定m，所有合法索引输入有同一总长度n=m+1+ℓ(m)，避免借总长度通道泄露位置。

## 3. INDEX属于NP_M

从左向右读取x，维护位置计数t。每遇到一个1，非确定性选择“此位置是否为最终见证”；选中一次后保存j=t，不再改变j，同时继续计数到m。可以不选，未选分支最终拒绝。

在#后解析z，维护长度计数及数值v。v采用饱和到m+1的更新v←min(m+1,2v+bit)，故非法巨大索引也只占O(log(m+2))位。检查符号/#、z长度恰为ℓ(m)、v∈[1,m]。当且仅当已选位置且v=j时接受。

正确性：若指定位置为1，选择那个位置的分支接受；若指定位置为0，没有任何保存同一位置的分支，全部拒绝。非法输入由各分支共同语法检查拒绝。

寄存器t,m,j,v及长度计数只有固定多个，均≤O(n)，空间O(log(n+2))。逐位计数/比较即使用朴素位操作也只需O(n log(n+2))时间；所有分支都有此界。因此INDEX∈NP_M。

## 4. INDEX不属于P_M：可区分前缀证明

假设确定性算法使用s(n)位可变状态。固定m以及n=m+1+ℓ(m)。对每个x∈{0,1}^m，观察读取x#之后、准备处理索引时的完整内部配置。若算法有内部停留计算，取确定的下一输入就绪配置；若提前决定答案，决定状态也必须保留并计费。

若两条不同前缀x、x'有相同配置，选一个x_i≠x'_i的位置i，追加相同ℓ(m)位编码z。算法面对相同配置和相同后缀必给同一答案，但两输入的正确答案相反，矛盾。

故2^m个前缀必须对应2^m个不同配置，因此s(n)≥m（固定控制编码若单列，只差O(1)位）。因为n=Θ(m)，任何精确单遍算法需要Ω(n)空间，不可能O(log n)。多花时间也不能恢复已经丢失的前缀信息。

因此：

P_M ⊊ NP_M。

## 5. 与LLM覆盖联合

LLM-SIMULATION.md证明：对每个满足明确封闭profile的≤200B参考LLM策略，存在M内的同输出策略；确定性解码用确定性M，随机解码用同资源随机M。TASK-SPACE.md给出逐输入输出分布相等如何保持任务成功标准。

RANDOMIZED.md进一步证明INDEX不在错误≤1/3的随机单遍logspace中。因此没有因为允许LLM采样就丢失该反例。

这三个论证联合给出的是：算法空间足够容纳所定义封闭LLM代理，但仍有一个NP_M语言超出其确定性甚至有界错误随机判定能力。

INDEX在标准图灵机上属于P（存储或回读x即可），所以本结果没有解决标准P/NP。若取消单遍限制，INDEX可用对数工作空间反复扫输入解决；输入访问限制是实质条件。

覆盖的任务若已被参考LLM按同一全域成功标准解决，就必然也在模拟器能力范围内。因此分离见证不可能同时属于那个“已被参考LLM解决”的子集；若要求两者同时成立，条件本身矛盾。这里要求的是覆盖该子集，同时在更大的输入任务宇宙中有反例。
