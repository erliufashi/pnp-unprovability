# INDEX对随机单遍算法也需要线性空间

状态：完整信息论论证，待独立审查；不是有限样本实验或标准随机复杂性下界新发现。

## 模型

沿用MAIN.md的单遍输入、空间和输出协议，允许内部随机转移/独立随机位。随机位不是外部计算oracle，不能在可回读随机带上隐藏未计费状态；使用PRNG时全部输入相关PRNG状态计入工作空间。要求每条运行满足多项式时间界，且对每个合法输入，正确概率≥2/3。算法必须对所有非法输入按其判定规范处理，但下界只需合法输入子集。

## 从流配置到消息

固定m，X为均匀随机m位串。令M为算法读取X#后的内部配置，至多s(n)位，n=m+1+ℓ(m)。接下来给索引i的固定宽度编码，算法仅从M和未来独立随机性生成答案。它不能重读X。

对每个固定i，平均到均匀X后的错误率仍≤1/3。把随机后续解码替换为每个配置下的最优确定性预测，不会增大平均错误；记其预测为g_i(M)，错误位E_i=X_i XOR g_i(M)，错误概率ε_i≤1/3。

## 熵界

二元熵h2(p)=−p log2 p−(1−p)log2(1−p)。因为给定M及E_i即可恢复X_i：

H(X_i | M) = H(E_i | M) ≤ H(E_i) = h2(ε_i) ≤ h2(1/3)。

链式法则及条件熵次可加性给：

H(X | M) ≤ Σ_i H(X_i | M) ≤ m h2(1/3)。

而H(X)=m，所以：

I(X;M) = H(X)−H(X|M) ≥ m(1−h2(1/3))。

信息量不超过消息熵，H(M)≤s(n)，因此：

s(n) ≥ (1−h2(1/3))m ≈ 0.0817m = Ω(n)。

固定控制状态若另计，只造成加性常数，不影响下界。

若允许公开共享随机串R，也可以对R条件化同样证明：R独立于X，H(X|R)=m，且I(X;M|R)≤s(n)。所有输入相关的随机读取地址/位置仍须计入M；未来随机性不能偷偷携带前缀信息。

## 结论与覆盖关系

INDEX∉BPP_M，其中BPP_M是本单遍logspace多项式模型、逐输入错误≤1/3的语言类。因此它比仅证明INDEX∉P_M更稳健，足以排除“LLM采样使下界失效”的疑虑。

不声称BPP_M⊆NP_M；本论证只需要一个INDEX∈NP_M且INDEX∉BPP_M的见证。NEQ等问题存在随机指纹算法，所以没有用它们充当随机分离见证。

错误率若只在某个有利输入分布上限制，或者允许重新读取输入、无限KV缓存、外部索引存储，本证明不能原样应用。TASK-SPACE.md的分布任务覆盖与这里逐输入最坏情况判定要分开。
