# 封闭≤200B LLM的统一模拟定理

状态：关于明确定义profile族的形式定理；没有下载、部署或测量实际200B权重，也没有证明其等价于人类。

## 1. 参考profile

一个profile π包含：

- 固定、可有限编码的架构/推理程序，以及参数量≤200,000,000,000的固定权重；每参数与算术操作使用指定有限位精度及舍入语义。
- 有限token字母表和一次性输入协议；上下文上限C固定，不随输入长度n增长。超限输入的拒绝、截断或滑动窗口规则预先确定并可流式执行。
- 一个固定有限上界S，覆盖所有可变内部信息：输入缓冲、KV、激活、输出反馈窗口、控制/位置/运行计数器、PRNG状态等。只读固定权重不是可写外部记忆。
- 固定有限输出预算D及内部运行预算τ，或一个可明确推导的等价最坏情况界。超时/超输出的返回值也属于策略定义。
- 确定性解码，或明确的有限精度随机采样内核。独立随机位不提供任何外部求解结果；随机状态/可寻址位置计入S。
- 不调用工具、检索器、外部图灵机、人类反馈或可回读的无限输出日志。若输出被再次输入，只能通过已计入S的有限窗口。

固定系统提示/格式协议可放只读程序，不能包含随任务变化的答案oracle。原始字节分词等预处理若使用额外资源，必须一起计入profile；本定理默认输入已经是有限字母表token流。

**200B和“不调用外部图灵机”单独不蕴含以上条件。** 特别是无限KV、无限可回读自生成文本、精确无限实数都可能破坏有限状态前提。这些条件是本备用分支采用的封闭部署语义，而非由参数量证明的事实。

定理量化的是所有满足profile的权重/程序，不靠挑选一个无能或全零模型来使覆盖成立。C、S、D、τ可以是任意巨大的固定常数，不限制成小玩具值。

## 2. 可计算的模拟编译

给定profile的有限描述，生成如下单遍程序A_π：

1. 单遍接收token流，按π的策略保存固定有限输入窗口或作超限判定；需要输入长度时加O(log(n+2))位计数器。
2. 使用同一位级权重编码、有限精度算术和舍入语义逐步模拟π；保留全部S位内部状态。程序/权重是只读固定描述，不随输入改变。
3. 采用同一随机位耦合（若随机）执行同一采样内核，逐token产生同一输出；保持相同的D/τ超限行为。

这是解释/编译原计算过程，不展开所有可能提示的真值表，也不把有限域查表冒充高效覆盖。

## 3. 资源界

对每个固定π，其S、程序寻址开销和模拟算术开销均为常数。输入扫描花O(n)步，其余推理至多一个依赖π而不依赖n的有限常数K_π。故可用：

Space(A_π,n) ≤ S_π + O(log(n+2)) = O(log(n+2))；
Time(A_π,n) ≤ a_π n + K_π，至多多项式。

若实现采用更通用的有限程序解释器，逐步模拟只有依赖π的固定开销，仍满足上述渐近界。这里是数学资源覆盖，不是已经实测某硬件达到相同秒级时延或能装下200B权重。

确定性π得到M内确定性转导器；随机π得到M内概率转导器。若π对某布尔任务逐输入错误≤1/3，模拟器也满足同样条件，故该语言属于BPP_M。不能把随机策略未经去随机化就写成P_M；本项目另外证明INDEX不在BPP_M，以兼容这种覆盖。

## 4. 成功指标保持

对每个输入x及每条耦合随机序列r，有：

A_π(x;r)=π(x;r)。

因此输出分布逐输入相同。对任意事先固定的有界损失ℓ(x,y)、分布μ和阈值ε，二者风险完全相同；对逐输入成功概率或确定性全域正确性也相同。不是只在有限评测样本上相等。

TASK-SPACE.md规定输入输出编码必须是原样接口或计入M资源的适配器，防止把困难求解藏到外部预处理/评分反馈中。

## 5. 不适用的反例

一个同样只有有限权重、没有外部工具、但允许KV随n线性增长的模型，可以把整串x存到自己的KV，等索引i出现后取x_i。它可能解决INDEX，且不满足固定S前提。这直接说明为何“200B且无外部TM”不能无条件推出本定理。

同样，不限可回读输出的模型可能把输出当外部工作带；不能把它算作这里的封闭有限profile。若用户将代理空间扩展到这种无限资源版本，T3当前证书必须失效或进入待证，不能沿用这个结论。
