# “足够解决”的操作定义与人类代理边界

## 1. 任务不是一句自然语言标签

任务τ至少指定：输入集合X、输出集合Y、信息/接口协议、正确关系或有界损失ℓ:X×Y→[0,1]、输入分布μ或最坏情况口径、成功阈值ε、允许的时间/记忆/交互资源。评分器可以用于离线评价，但不能在求解过程中把答案反馈给策略。

输入输出编码默认就是token接口。若有适配器，必须是固定、可计入同一单遍logspace多项式模型的转导器；不得用外部无限计算把答案预先编码进提示。输出解码器只能读取输出及已计入资源的元数据，不能偷偷重读全部输入。

对随机策略π，分布任务的成功标准可以是：
Risk_τ(π)=E_{x~μ,r}[ℓ(x,π(x;r))]≤ε。

也可选择逐输入P[输出错误]≤ε，或确定性全域正确性。口径必须事先声明，不能在下界和覆盖两部分偷换。INDEX分离使用逐输入最坏情况，而LLM常见测评可以使用分布风险。

## 2. LLM代理任务空间

对一个预先选定、与分离见证无关的封闭profile π，定义T(π)为它按上述标准能解决的任务集合。这个定义不要求我们能有效判定τ是否属于T(π)。

覆盖的有内容要求不是一句T(π)⊆A的命名，而是独立构造统一编译器π↦A_π，证明对每个x输出分布相等及资源界。LLM-SIMULATION.md已给这个构造。因此对所有τ，π满足成功标准就蕴含A_π满足同一标准；对所有输入分布同时成立，不是靠记住有限测评答案。

对满足封闭profile的所有≤200B模型取并集仍可覆盖：每个模型对应一台固定M算法，常数依模型变化。不能把“对每个固定profile存在一个常数”偷换成“任意随输入n增长的profile都有统一常数”。

## 3. 人类足够接近：建议的可审计假设

不要把“人类能解决”定义成所有人类、任意时间、任意工具、任意未来数学成果的并集。那个对象既不操作化，也不由200B量级推出。

可定义H_op：指定人群、每任务时限、可用笔纸/记忆/工具、输入长度与模态、是否协作、成功阈值后，在预登记任务族上能够达到标准的人类策略任务空间。若比较的是无工具LLM，不能让“人类基线”无限使用互联网和程序后再声称条件相同。

建议把人类接近度作为额外假设H(ν,δ)：对事先固定的任务分布ν，H_op任务中至少1−δ的质量也由参考π达到同一成功标准。δ是目标/假设参数，不是本项目测量值。

若H(ν,δ)成立，由统一模拟直接推出受限算法空间覆盖同一比例的人类代理任务。若要经验支持，需冻结模型/解码/预算、预登记任务分布、人工基线、独立评分和误差区间；不能用模型自评或挑选样例证明。δ=0的全域覆盖尤其不能从有限评测推出。

本次采用用户允许的退一步版本：证明对明示封闭200B LLM的形式代理覆盖；**不宣称H(ν,δ)已验证**。也没有下载/部署/测量真实200B模型。200B仅是参考策略规格，不是能力定理。

## 4. 时间与实用性

形式覆盖证明空间O(log n)、时间多项式，并复用原推理过程而非指数查表。但实际常数可能极大，没有进行硬件秒级时延或显存验收。如果任务有严格墙钟限制，须另加同硬件端到端基准；当前证书不覆盖这种未经实测的性能主张。

## 5. 为什么反例不能同时是代理已解任务

若算法空间覆盖T(π)，而某任务按照完全同一成功标准不被算法空间解决，那么该任务必不属于T(π)。因此不能同时要求“反例超出算法空间”与“它已经被参考LLM按该标准解决”。

本分支的INDEX是更大标准输入宇宙中的反例；封闭LLM可解子集被覆盖。它不是一个已测的人类轻松任务，也不证明人类能无界单遍解决INDEX。若输入/任务宇宙只剩固定有限长度，渐近分离也就不再是原定理，必须保留二者的区别。
