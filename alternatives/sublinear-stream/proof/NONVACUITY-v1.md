# 有限horizon覆盖与渐近分离的非空洞性

状态：量词/任务域审计，待独立复核；不修改旧T3或用户的标准数学目标。

## 1. 一个独立的有限前缀事实

给可执行reference π、有限精度/词表、明确有限运行预算。固定H并限制输入/输出总执行在该horizon内，则其全部分支是有限状态树，可直接运行π并保留至多H的原生状态；超过H置overflow并拒绝。该截断程序在固定π/H下是常数工作空间，因而也属于通常允许模型相关常数的O(log(n+2))类。

构造复制的是π的可执行行为，不是凭空取得语义任务答案；不证明π接近人类。实现可以直接保留有限原生工作带，不必真的展开巨大表。

所以单凭“在某固定有限任务范围内功能足够”不能迫使一个渐近算法类有强表达限制。常数可随H增长得很大。

## 2. 三个不同的量词

- ∀固定H，∃B_H，使该horizon内复制π且渐近空间小。
- ∃同一B及同一小数值预算，同时覆盖所有H。
- 固定某B_H，在给定具体输入/任务分布上满足κ/δ/墙钟/物理内存。

第一项不推出后两项。若每次看到输入长n后才选H=n+D(n)，便不是一个固定阈值、固定描述/常数的算法，不能据此声称统一log空间。

horizon应预先声明。最保守的任务范围可用n+D(n)≤H（对全部随机分支成立）；不能仅凭一次运行恰巧早EOS就称整任务有相同资源保证。RNG、输出、控制步骤也另按已声明口径计费。

## 3. 截断与全域混合不同

没有全域kernel编译器时，上述overflow程序只复制T(π)的H限制，不能冒称π全部无界任务空间。

若另有全域精确κ，则可考虑在H后从内部KV重建κ，得到全域保持行为的混合；其正确性/资源常数需另一构造证明。这里不把候选当已证，也不使用同层研究节点作隐藏前提。

## 4. 分离见证在哪个域

若一个流式类在某无界任务宇宙U上有INDEX类反例，而有限人类代理域只是U的很小范围，不能从存在外域反例推出“人类关心范围内发现难题”。

若类已覆盖π可解任务子集，就不能同时要求分离见证也在该被覆盖子集内；那会直接矛盾。合理的更强要求应固定共同U、输入协议、资源预算和实际相关大小范围，说明见证与覆盖子域的关系。

巨大固定H可把全部所关心实例留在原生分支，而把渐近分离推到更大尺度。形式终止条件可能真实成立，但解释力不能超过量词所说的内容。

## 5. 建议的更强门槛（未自动采用）

事先固定baseline/profile/任务分布、数值资源与代码/metadata预算、输入大小/交互范围；禁止以任意未付常数吸收硬件限制；报告见证大小及是否在相关范围。200B参数数目本身不提供这些事实，功能复制也不证明human adequacy。

这些是可能的新终止标准，需要用户选择并正式验收。原限定T3保持原义；标准P/NP或其ZFC不可证性没有由本审计得到新结论。
