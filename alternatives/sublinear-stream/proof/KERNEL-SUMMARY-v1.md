# 有限query/归一化参数的左折叠历史摘要

状态：限定核的完整归纳论证，待本批独立复核。不是任意Transformer/200B模型的覆盖定理，也不扩大T3证书。

## 1. 参考语义必须明确

设Ω是有限的数值/错误字母表，N=|Ω|。它包含零、max初值及需要的错误标记。query集合Q有限，K是固定有限宽度的key字母表，value有r个Ω通道。固定纯、总、可计算的位函数：

σ:Q×K→Ω（score）；μ:Ω²→Ω（参考max）；
⊕、⊖、⊗、⊘:Ω²→Ω；E:Ω→Ω。

它们是参考程序真实使用的舍入/primitive，包括所有累加器和归一化值；不能只量化激活却让分母无限精度。错误以有限标记在每个假设计算中totalize，不让未被选中的反事实分母触发宿主异常。

历史H_t=((k_1,v_1),...,(k_t,v_t))只追加，不删除或修改旧记录。score不另外依赖未编码的历史索引/时间。所有归约严格按j=1..t左折叠，初值固定。没有交换、结合或实数代数假设。

定义s_j(q)=σ(q,k_j)。字面参考先求：

m_q(t)=Fold_μ(m0; s_1(q),...,s_t(q))；
u_j(q,m)=E(s_j(q) ⊖ m)；
z_q(t)=Fold_⊕(0; u_1(q,m_q(t)),...,u_t(q,m_q(t)))。

最终输出通道：

y_qr(t)=Fold_⊕(0; ((u_j(q,m_q(t)) ⊘ z_q(t)) ⊗ v_jr)_{j=1..t})。

这里每个term都使用最终m和最终z，而不是当时的running值。空历史按这些fold的初值语义定义；若实际API另有空输入处理，须单独适配。

## 2. 摘要状态

为所有q∈Q、m,z∈Ω及通道r'维护：

M[q]=m_q(t)；
D[q,m]=Fold_⊕(0; (u_j(q,m))_{j≤t})；
A[q,m,z,r']=Fold_⊕(0; ((u_j(q,m) ⊘ z) ⊗ v_jr')_{j≤t})。

所有m/z是固定假设参数；不是把D的当前值代入A更新。

初始化M[q]=m0，D与A全为0。追加(k,v)时，对每个q计算s=σ(q,k)：

M[q] ← μ(M[q],s)；
对每个m令u=E(s⊖m)，D[q,m]←D[q,m]⊕u；
对每个m,z,r'，A[q,m,z,r']←A[q,m,z,r']⊕((u⊘z)⊗v_r')。

查询q只需m=M[q]，z=D[q,m]，返回A[q,m,z,r']。

## 3. 精确性证明

对历史长度t归纳。

基例t=0：M、D、A分别等于相应空fold初值，成立。

归纳步：假设所有q,m,z,r'的不变量对H_t成立。追加第t+1条记录后，每个更新只是把对应左折叠的最后一个term接到旧fold值；同一primitive、同一参数次序，没有重结合，所以新M/D/A分别等于H_{t+1}的字面fold，逐位相同。

查询时，M给出完整历史最终m，D[q,m]给出同m下完整历史最终z；对应A[q,m,z,r']正是字面参考的每个最终归一化term按原顺序的fold。因此输出逐位相同。

选中的m/z即使依赖整个历史也没有问题，因为所有可能字母值的候选fold已经同时维护。证明不要求⊕结合、线性、可逆，也不要求μ是数学上的真正max，只要求参考操作/顺序一致。

## 4. 错误隔离不是细枝末节

不能枚举z=0时真的让宿主程序抛异常并终止整个编译器。反事实A[q,m,0,*]可以变成ERR，但其他参数的摘要仍更新；查询时仅观察实际选中路径。

本定理保存的是明确totalized数值语义。若参考API输出第一异常的发生时间、设备异常标志、OOM/墙钟超时等，需要另行模拟那些协议；不从本定理自动获得完整API等价。

## 5. 成本必须同时按历史与模型规模写

原始数值状态单元数：

K_cache = |Q|·(1 + N + N²r)。

每字母可用b=ceil(log2 N)位编码，另需枚举控制及当前key/value的存储。数值缓存位数O(|Q|N²r·b)，不依赖历史长度t；本核不必保存t或历史。若外围产生位置特征/计步，需要的O(log(t+2))位另计。

一次append调用score |Q|次，并对O(|Q|N²r)个固定参数单元做参考primitive。若primitive成本为T_prim，数值操作成本O(|Q|T_score+|Q|N²r T_prim)，查询r个值。普通工作带可以顺序扫描表更新，因为每格只依赖自身旧值、当前记录和固定参数；随机访存不是免费假设。保守引入poly(K_cache,b,模型描述)开销后，历史长度方向仍为多项式。

对b位宽、d维query，|Q|最多约2^(bd)，N约2^b，故缓存可达O(r b·2^(b(d+2)))位。对固定模型这是与t无关的常数，但对模型宽度/精度指数巨大；并未得到在实际200B/墙钟预算内可运行的工具，也未给多项式模型规模编译器。

所以“去掉历史存储”不能被表述成实际省内存，不能把指数常数隐藏后宣布接近人类可用性。正确结论只是一个精确可计算的历史摘要工具，成本已显式。

## 6. 覆盖边界

- 必须append-only；删除旧项的非结合fold没有通用逆操作。
- 本版只证明左折叠，不涵盖树形/分块GPU归约；不同归约树可改变位结果。
- score的所有位置/时间依赖须已经编码成有限query/key。动态改写旧key、额外未编码相对距离不包括。
- 一个attention核的引理不等于完整因果多层LLM模拟；跨层归纳、输入/输出、随机节点顺序及预算协议仍需另证。
- b随输入增长时不能继续称常数空间，必须将N(n)、Q(n)代入成本；若参考精度随时间变化，也不能沿用固定域的旧fold状态。

## 7. 本批实验的角色

tools/tiny_query_summary.py在9个半整数数值字母加ERR的玩具域实现相同公式，采用非结合饱和加法、明确舍入和反事实除零。它比较字面完整历史与摘要，另以直方图丢顺序和running分母替代final分母作为负控制。

这些只是实现sanity check，不替代第3节归纳，不是float32全域、真实GPU或真实LLM测量。常数表数量由实际数组长度检查；测试harness为构造参考保留历史/克隆状态，不属于被证明的流摘要算法本体。
