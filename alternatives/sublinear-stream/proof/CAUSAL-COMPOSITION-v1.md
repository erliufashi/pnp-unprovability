# 条件性因果提升：从精确kernel接口到完整增量策略

状态：本批限定组合引理，待独立复核。它是“若有满足接口的kernel模拟器，则可提升”的模块，不假定M14已成立；方向D6可另将M14代入。不是任意LM/GPU的无条件覆盖，也不扩大T3。

## 1. 有类型的参考策略

采用CAUSAL-CONTRACT-v1的增量reference π_inc。固定有限层数L和每层头数H_ℓ、固定有限hidden/query/key/value字母表、只读有限权重。

对位置p，输入当前token x_p，经有限embedding及计费位置程序ρ(p)得到h_0,p。对层ℓ及其每头a：

(q_ℓa,p,k_ℓa,p,v_ℓa,p)=φ_ℓa(h_{ℓ−1,p},ρ(p))。

将(k,v)追加到该头不可变历史H_ℓa，然后用同q读取精确reference kernel K_ref(H_ℓa,q)。所有头的输出经固定纯逐位置post-map Φ_ℓ与当前h_{ℓ−1,p}生成h_ℓ,p。

过去位置的KV不重算、不删除、不动态改尺度；φ/Φ不得通过别的通道读原prompt、旧hidden列表或未计费外部缓存。位置程序须有O(log(p+2))空间与多项式时间。所有类型和有限错误字母均明示；若有终止错误分支，由同一有限控制规则处理。

此处规定push后read，包括当前位置自己；若使用其他顺序，必须把另一顺序作为reference重新说明，不能在实现间偷换。

## 2. kernel编译接口假设

每头有状态z、初始化Init、Push(z,k,v)、Read(z,q)及历史精化关系R(H,z)：

- R(空历史,Init)；
- R(H,z)蕴含R(H追加(k,v),Push(z,k,v))；
- R(H,z)蕴含对所有合法q，Read(z,q)=K_ref(H,q)，按word逐位相同。

同时给出明确空间S_ℓa(t)、push/read时间界。q/k/v生成不是接口外部oracle，资源须另计。接口可以被不同具体核实现；本提升证明不依赖某个特定树的括号。

## 3. 单遍模拟构造

编译器嵌入相同embedding、φ/Φ、ρ、采样及有限控制程序，只将每头的完整历史换成其z状态。

每读到新token，按参考相同层/头顺序算q/k/v，调用Push，再Read，算本层hidden。保留当前token/hidden和固定层/头scratch，处理完即丢弃不再需要的原token；不保存整个原prompt。

prompt EOF前不输出答案。之后按参考采样内核一次只生成一个token，写到只写输出；若EOS或token预算到达则按参考停，否则把当前生成token作为下一个输入反馈，仍不回读输出日志。

## 4. 外层位置、内层层/头归纳

位置p开始前，不变量为：
(a) 每头的完整参考历史与编译状态满足R，历史长度均为p−1；
(b) 位置/有限控制/上一次最终hidden及采样状态相同。

基例为空历史/给定固定初始化；若有BOS等固定初始token，双方按同一有限规则先处理，可并入初始化。

进入位置p：两边当前token相同，ρ及embedding相同，故h_0,p相同。

假设当前层前层hidden相同。每头的φ是同一纯程序，得同q/k/v。原历史与编译状态经Push保持R，Read返回同一word输出。因此这一层的全部head输出相同，同Φ得同h_ℓ,p。逐层归纳至L成立。

处理中不能假定所有头已同步到同一个长度：已处理头为p，未处理头仍p−1。分别维护每头计数（含seed时p+1与p）或用明确阶段指针标识新/旧shape即可；固定头数下额外O(ΣH_ℓ log(p+2))位。当前层的head输出齐备后才计算post-map。

全部层完成时，每头历史/编译状态都推进到p，最终hidden与有限控制一致，恢复外层不变量。由此所有prompt token可单遍模拟。

## 5. 随机采样、反馈与停止

前向无内部随机调用。最终采样读取同一logits/hidden、同一RNG状态或同一随机位序列，且内核按每条路径有界。因此输出token、消耗随机位数和新RNG状态相同；不能用无限拒绝采样的期望界偷换最坏情况多项式界。

EOS与显式token预算D(n)的决定相同。非EOS反馈是刚生成的同一token，再用第4节归纳处理。输出流在每个耦合随机序列上相同，故其分布相同。默认编译策略不保存输出历史；测试harness的输出列表/trace只能用于被动评价，不能反馈帮助模型。

D(n)须为声明的多项式并可用O(log(n+2))空间计算/控制。任意给一个指数大预算不属于该结论。空/非法输入若在域内，需同一固定有限返回/终止规则；不靠外部预处理求答案。

## 6. 资源与实例化

令T=n+D(n)+固定初始化长度，D多项式则log(T+2)=O(log(n+2))。一般编译空间可界为：

Σ_ℓa S_ℓa(T) + 当前固定层宽scratch + 位置/各头/预算计数 + RNG空间。

若代入M14且各头数值参数固定，则S_ℓa(T)=O(K_ℓa b_ℓa log(T+2))。固定有限层/头/宽度、有限PRNG或计费随机位指针、O(log T)位置程序给出总O(log(n+2))工作空间。

push/query、局部word程序、ρ和采样均有输入方向多项式时间，且处理至多T个token，故总时间多项式。可写成T乘Σkernel成本/局部成本的多项式；标准TM数组访问/计数成本不能忽略，但保守模拟仍为多项式。

模型系数ΣK_ℓa仍可对精度/宽度指数巨大。只读200B权重是固定模型描述，不是额外输入相关工作带；这个渐近结论不证明模型规模多项式编译、实际显存可装下或墙钟可用。

## 7. 任务指标与范围

给定同输入及同随机序列，功能输出相同。因此对事先固定的输出损失/分布/成功阈值，风险保持。这不自动保持真实硬件OOM、墙钟超时、浮点异常发生时刻或严格latency指标；如任务观察这些，需另给可计费的守卫模拟或更强成本证明。

该reference允许某些无界append-only历史，却增加了增量/核/位置/控制条件。它不是T3全部固定profile的无条件上位族，也不是从头batch重算的自动等价替代。真实模型是否满足契约、人类近似H(ν,δ)、实际200B性能均未验证。

在这些条件下，若某π_inc对INDEX全域有错误≤1/3的判定能力，则其单遍log空间模拟器也有，与已证INDEX线性空间下界冲突。这个条件能力上限不是标准P/NP结论，更不是对所有无外部TM的200B模型的无条件断言。

## 8. 本批原型口径

causal_model_probe.py只实例化两个有限玩具配置（2层2头），完整KV reference与森林模型逐步比较prompt/生成中的q/k/v、head输出、hidden、临时head计数、输出及RNG状态。采样用固定4位抽样、整数权重总16，避免无界拒绝循环。

默认stream没有observer、EOF前不输出答案、不保存输出列表。测试observer/list是被动harness，可从策略中删除；不能当免费工作记忆。测量只报KV/森林数值单元，不是RSS，PRNG/控制另计。小规模时编译表可能比原KV更大，不能反称实际内存优化。

有限对照不替代上述接口/双归纳证明，不是实际200B/任意GPU认证；它只检查该具体实例的数据流和控制实现。
