# 只改存储调度、不改有限精度运算的attention行处理

状态：关于明确数值DAG族的限定定理；不是对FlashAttention、PyTorch或任意200B产品内核的实测认证。

## 1. 固定参考计算，而非只写一个实数公式

输入Q,K,V各有C行、宽度d。数值字母表F_b有限。每个primitive（加、乘、FMA、除、exp、比较等）必须指定为确定的位串映射：同输入位串给同输出位串，舍入模式固定，没有可观察的全局浮点异常标志副作用。

对每行i，参考DAG G_i定义：
- 每个分数s_ij的原始点积primitive及归约树；
- 行内max、exp及归一化和的原始归约树；
- 各p_ij及每个输出通道的加权和原始归约树。

若原节点是FMA，不可替换成先乘再加；若原归约是树形，不可改成左折叠。实际内核是否满足这个DAG必须另验，不能凭公式相同推断。

假设G_i只依赖固定Q/K/V及本行中间值，节点数O(Cd)，图与primitive顺序能由固定程序均匀生成。无跨行的中间数值依赖；causal mask或bias若可从i,j及已存参数在计费空间内生成，可以行内处理。全张量统计量/量化尺度暂不包括。

## 2. 定理：位级不变的O(Cd)活跃存储

保持Q/K/V只读。对i=1..C：
1. 生成并按任一合法拓扑序计算同一个G_i，保留本行全部必要节点，至多O(Cd)值；
2. 保存d个最终输出；
3. 释放本行非输出中间值，然后处理下一行。

输出全部保留占Cd，输入Q/K/V占3Cd，本行DAG占O(Cd)，索引/地址占O(log C)。总峰值O(Cd·b+log C)位，固定b时O(Cd+log C)。没有把预存Q/K/V假装成免费外部KV。

位级正确性由DAG归纳：叶子同位串；若父节点已同位串，节点的primitive及参数次序与原图相同，输出也同位串。重排互不依赖的不同节点不会改变纯函数值。因此每个输出行、整个输出张量逐位相同。

这不是代数重结合；原归约树完整保留。共C行，每行O(Cd) primitive，时间O(C²d)乘固定精度primitive成本。生成图的辅助程序也须满足所声明的空间/时间，不能把任意巨大DAG当免费oracle。

## 3. 固定层数及采样

若其余固定层数L的操作为类似逐token/逐行局部DAG，使用前后层缓冲，保持O(L C d)值，L固定则仍线性于C。只读权重常量不充当输入相关工作带。

当前定理先限定数值前向无内部随机节点（通常推理dropout关闭），随机性只在前向之后的输出采样。前向位相同、同采样内核、同随机位耦合，则下一token同分布；逐token归纳到多项式步数仍保持输出分布，且只保留有界窗口。

内部dropout的随机调用顺序、设备并发非确定性、数据依赖PRNG推进不在这个结论里。不能只说“概率分布差不多”就写成逐位等价。

## 4. 为什么常见的数值捷径不够

float32中a≈1e20、b≈−1e20、c≈3.14时，(a+b)+c得到c，而a+(b+c)得到0。数学实数相等不能保证浮点重结合相等。在线softmax、改分块规约或不同GEMM形状可能更换归约树，未经核验不能声称逐位不变。

## 5. 原型口径与剩余义务

tools/attention_probe.py比较一个明确的canonical标量程序与其逐行改调度版本：Python计算后按struct打包到binary32，exp使用同一host libm后舍入。它不是所有硬件IEEE/FMA/exp实现的黄金模型，也未部署实际LLM。

finite sanity checks验证多个小C/d及causal情形的输出位串、重结合反例，以及tracemalloc辅助峰值；峰值不包含测量开始前分配的Q/K/V，理论上它们仍计入总空间。有限测量不证明渐近界，渐近界由第2节活跃值计数给出。

资源错误也可能是可观察输出：优化后少OOM或改变超时不能自动宣称与原返回协议完全相同。除非明确复现这些守卫，当前位等价只指完成正常数值求值的功能语义。
