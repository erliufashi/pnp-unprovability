# 有限state随机INDEX：自含entropy及精确安全系数

状态：局部理论，待独立复核。沿用明确的public-m有限流协议：X均匀于{0,1}^m，I均匀于m个坐标且独立，I在payload之后才出现；一个固定程序/ROM独立本次X/I。以下完整重推信息不等式，不把另一研究工具作隐藏同层前提。

## 1. 完整prefix state与随机源

M为读完payload而未知I时的全部保留配置，最多2^s种，故H(M)≤s。RNG/时钟/地址等若影响future必须在M内，或是与X条件独立的新鲜随机源；不能经外部日志/输入副本恢复X。

未来decoder对固定i给估计Xhat_i(M,R)。这里R为独立新鲜coins；闭合PRNG若其state已在M中则可视decoder确定性。程序和ROM可很大但固定，不能携带本次X答案。

## 2. 自含推导

设第i位平均错误e_i，整体平均e=(Σ_i e_i)/m≤γ≤1/2。

给定M/R时，二元error bit E_i=X_i XOR Xhat_i可重建X_i，且新鲜R不再提供X信息，所以：

H(X_i|M)=H(X_i|M,R)=H(E_i|M,R)≤H(E_i)=h2(e_i)。

再由条件entropy链式与凹性：

H(X|M)≤Σ_i H(X_i|M)≤Σ_i h2(e_i)≤m h2(e)≤m h2(γ)。

另一方面，m=H(X)，I(X;M)≤H(M)≤s，故H(X|M)≥m−s。合并得到

s≥(1−h2(γ))m。

单个e_i不必≤1/2；上面的二元error恒等式和凹性仍成立，最后只用平均e≤γ≤1/2的单调性。若要求每个输入error≤γ，则当然满足这里的均匀平均条件；反向不能由平均推pointwise。

## 3. γ=1/3的无浮点见证

h2(1/3)=log2 3−2/3，所以c=1−h2(1/3)=5/3−log2 3。

精确整数计算：

3^48=79766443076872509863361 < 151115727451828646838272=2^77。

因此log2 3<77/48，c>5/3−77/48=1/16。取m=16s+1，就有c*m>m/16=s+1/16>s，不可能达到均匀平均error≤1/3。

c约.081704及约12.239倍的更尖阈值可作数值信息，但本见证使用16s+1和整数不等式，不靠浮点近似决定严格不等式。

## 4. ND预算与上下文必须另付

要同时给同s预算的ND_s证书，仍检查8ceil(log2(m+1))+64≤s。m=16s+1对某些小s不fit这个保守ND编码，不由此宣称ND不可能。

v2单位澄清：若C_x表示payload大小范围，16s+1≤C_x让保守见证位于该范围。若C_wire表示完整输入data-bit容量，则须m+b≤C_wire，EOF/头部/传输framing另计。两者不是同一个context单位。这些是本证书进入相应范围的足够条件，不是所有hard task的必要条件；条件失败不说明域内都容易。v1原字节保留，entropy/整数系数结论不变。

这里均匀X/I的风险不是实际LLM任务分布。没有测真实baseline state、context或human adequacy，随机π也不自动归为D_s。新finite-state分离不改T3，不解标准P/NP或其ZFC不可证性。
