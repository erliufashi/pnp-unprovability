# 紧凑检索族的状态下界与模型系数量词

状态：本批限定证明，待独立复核；不是标准P/NP、实际200B或单个任意模型的不可能性结论。

## 1. 假设与被计费状态

固定d≥1、m=2^d。reference在读完任意x∈{0,1}^m后，接收晚到的d位索引j，返回x_j，j=0,...,m−1。NEURAL-RETRIEVAL-v1提供一个紧凑神经score核实例；下面下界仅使用检索性质，作为可独立的条件引理。

候选编译器只能单遍接收x；query到达后不能回读x或借外部工作带/日志。它的只读模型/程序可依赖d，但不能依赖任务输入x。EOF/query之前不能把x通过外部输出或免费可读时钟送给后续decoder。

状态位s包含全部输入相关信息：工作带、寄存器、控制/PC、输入相关地址/随机状态、存储长度等。若只称指数多个有限控制是“免费常量”，便不满足这里的数值预算。独立于x的只读模型/公共随机性可已知给双方，不携带x。

## 2. 确定性下界

设不同x/x'在query之前产生相同完整状态。选它们不同的一位j，继续给相同query。后续可见信息相同，必给同答案，但正确答案不同，矛盾。

所以2^m个prefix需要2^m个不同状态。若完整状态最多可用s位编码（所有元信息已计入），则2^s≥2^m，即s≥m=2^d。变长编码若需额外终止/长度信息，也必须计入；采用常见编码约定只差加性常数。

这个信息结论不靠限制query后的计算时间；没有丢失的x通道，再多计算也不能恢复全部位。

## 3. 随机/平均版本

令X均匀取m位串，I均匀独立取索引。M为读完X后的状态，剩余decoder只读M、I及独立噪声。假设在这个明确分布上平均错误≤γ<1/2（逐输入错误≤γ当然足够）。

对每个i用最优确定性预测g_i(M)，其平均错误γ_i不会比实际decoder更大，且γ_i≤1/2，平均γ_bar≤γ。令E_i=X_i XOR g_i(M)。给M、E_i可恢复X_i，所以：

H(X_i|M)=H(E_i|M)≤h2(γ_i)。

条件熵次可加、h2凹性及其在[0,1/2]递增给：

H(X|M)≤Σ_i h2(γ_i)≤m h2(γ_bar)≤m h2(γ)。

故s≥H(M)的上界与I(X;M)的下界合并为：

s ≥ (1−h2(γ))m。

更明确地，I(X;M)≤H(M)≤s，而I(X;M)=m−H(X|M)。γ=1/3时系数约0.081704。

若有独立于X的公共随机R，对R条件化全程同证，H(X|R)=m、H(M|R)≤s。任意免费可回读随机地址/数据若能携带x，必须先纳入状态而非暗作oracle。

这个平均下界针对uniform X/I；不能把它直接挪到任意人类任务分布。若query/值分布很偏或只关注少数位置，结果可能不同。

## 4. 参数化编译后果

NEURAL-RETRIEVAL的稀疏circuit描述s_model(d)=O(d log d)，dense展开也为poly(d)。如果一个适用于整个族、常数独立于d的单遍编译器承诺：

State(d,t)≤poly(s_model(d))·log(t+2)，

并对所有x/query精确或有界错误，则取t=m=2^d。右侧为poly(d)，第2/3节要求Ω(2^d)，对足够大d矛盾。

因此这个generic核族不能有这种普遍小模型系数的单遍摘要。不是从我们的指数上界倒推下界，而是通过具体紧凑检索实例另证。

对于确定性retrieval baseline，输出law是δ_(x_j)，逐输入TV≤γ等价于错误概率≤γ；所以不能仅用“允许近似功能覆盖”绕过此界，除非改变错误/输入分布/资源承诺。它不限制非确定性存在分支的验证模型。

这里也没有证明现有缓存上界中的N²、树形log t或全部系数最优；Ω(2^d)仅说明某个指数模型依赖不能普遍降成poly(d)，不是匹配所有指数率。

此结论不排除允许线性KV的普通多项式开销原生模拟，也不证明指数运行时间；这里只是数值状态预算。

## 5. 固定profile/200B边界

每个固定d只有有限query范围和horizon m。原复杂性类允许依profile的任意巨大常数，故s≈2^d也可成为固定profile的常量；这不反驳旧T3或一个固定语言的渐近分类。

“无poly模型系数的统一编译器”是无界compact模型族上的量词。对一个固定有限200B上限，不能把有限参数集的任意巨大常数说成渐近非多项式定理；只能对每个实际允许d给明确数值下界，并结合其任务horizon/预算判断。

该模块不是stock bilinear score或实际训练LLM；没有证明用户选定的某个baseline具有此检索能力。model-specific pruning、特殊key/query结构或宽松输入分布仍未被排除。人类代理H(ν,δ)也未验证。

## 6. 实验的正确角色

小d电路/exp/所有值字符串和query核验说明这个参考实现符合声明语义，随机大一点d只作sanity。一般下界来自上述计数/熵证明，不从有限测试外推。预期x_j只由被动测试observer检查，不给reference/编译器答案。
