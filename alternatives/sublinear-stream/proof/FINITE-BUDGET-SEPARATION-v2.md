# 固定数值state容量的有限INDEX分离

状态：自含的受限机模型结论，待独立复核；不是标准P/NP，也不是物理RAM测量。

## 1. 宇宙与机模型先固定

public m≥1，b=ceil(log2(m+1))。U_m是payload x∈{0,1}^m，随后b个bit编码late query j<m，最后EOF。目标输出x_j（0-based）。m/模型/程序在x及实际j之前固定，不得按它们换advice。

D_s为确定性、只读一遍流、至多2^s个保留配置的设备；输出在有效协议EOF后产生。ND_s使用相同状态容量与输入协议，但以存在接受分支定义yes。随机版本另记R_s，不把有采样的baseline自动说成D_s。

state是所有可影响未来的保留信息：寄存器、PC/阶段、input cursor、可读时钟/RNG/ROM地址、可回读日志/输出等。没有外部payload副本、重读输入或任意精度wallclock通道。ROM可很大，但固定且独立本次x/j；若地址本身携带输入信息，也在state内。

这是有限状态/保留配置容量模型。转移由静态电路或有限word程序给出；组合线只是当前配置与当前bit的纯函数，不能藏额外保留状态。它不是把CPU/Python全部瞬时物理字节归成下面的寄存器数。

本结论首先关于声明的有限U_m。若扩展为完整字符串语言，可对超长输入读到第m+b+1个符号即早拒绝，不要求无效任意长流也等EOF；有效输入仍EOF后答。不能一边要求无效无限长流全读完、一边免费忽略其无界物理cursor。

## 2. 确定性下界（无时间假设也成立）

在m个payload bit读完、query尚未知时，2^m个x映到至多2^s个完整保留配置。若m>s，则两个不同x/y同配置。取其一个不同坐标j，继续给相同j/EOF；确定性后继完全相同，却应输出不同bit，所以至少一例错误。

无需知道哪个摘要算法，也不依赖某个坏上界；任何固定ROM/程序都受同一计数。若实现把x藏进PC、耗时可读值或日志，该载体必须计入配置，不能据此规避。

故m=s+1是一个exact有限硬任务阈值。普通TM可存x再查询，或在可重读输入时用O(log m)空间再次扫描；INDEX不是标准NP难题。这里的限制是同一数值state及一遍协议。

## 3. 显式ND状态编码

先用b次二选一转移猜J，存为b-bit寄存器。扫描x时仅当当前位置I=J保存该位V；之后读late query Q，EOF时且仅当J<m、Q=J、V=1接受。无效guess永不接受。

若x_j=1，猜J=j有接受分支；若x_j=0，所有接受候选必须J=j，又记录了0，所以无分支接受。不是把guess本身当答案。

一个保守、可核对的编码为：

| 字段 | bits |
|---|---:|
| I/J/Q/L四个有界语义register | 4b |
| 输入cursor（最多m+b+1） | 2b |
| 两个局部scratch/index register预留 | 2b |
| 固定PC、阶段、valid/EOF/V/进位等flags及当前bit预留 | 64 |

m≤2^b−1且b≤2^b−1，所以m+b+1≤2^b+b≤2^(2b)−1，cursor的2b足够；I到m、J/Q到2^b−1、L到b都能用b位。阶段数固定，不把input-dependent分支身份当免费存储。

在声明的有界word/电路状态机中，比较、移位、增量是当前字段的纯有限转移，静态电路O(poly(b))，无额外跨输入bit的隐含栈或日志。若改用不同微码/硬件模型，其新保留字段须重新计费，不能直接沿用8b+64为物理上界。Python只是逻辑状态模拟器。

总保留配置可嵌入8b+64位，转移数O(m+b)、gate/bit计算poly(m)，程序描述随public m仅poly(b)。无效字符串的有界早拒绝保证cursor也在上界内。

## 4. 同一预算下何时得到分离

若m>s且8ceil(log2(m+1))+64≤s，则INDEX_m在ND_s但不在D_s。例如s=128、m=129满足ND编码128位。

若给出的ND上界不fit，只能说本构造没有给出该预算证书，不能判ND不适合或见证不存在。若π随机，覆盖类须选R_s及相应风险，不用固定seed伪装保持全部任务law。

## 5. 与充分性/上下文的关系

baseline属于所选数值预算类要另行检查其全部state；200B的只读参数数目不是这项测量。随机/实际任务分布更不能仅凭上述exact D_s结论决定。

v2单位澄清：C_x若是payload大小范围，m≤C_x表示见证位于这个范围。若C_wire是完整输入data-bit容量，还须m+b≤C_wire，EOF/头部/传输framing另计；不能由payload fit冒称整个context fit。超出相应范围仍是外域硬任务；fit也不自动证明人类可解或baseline有该能力。v1保留原字节，数值state/collision/ND结论不变；旧T3及标准P/NP/ZFC目标不改。
