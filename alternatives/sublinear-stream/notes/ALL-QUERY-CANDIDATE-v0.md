# 新候选工具：枚举有限查询/归一化值的历史摘要（v0，未认证）

这只是本小时产生的新研究候选，不在已认证T3或本小时已证明结论之列。值得下一检查点验证，不能把公式草图直接改成代理覆盖证书。

## 动机

行调度仍需保留C个KV。若固定有限精度、宽度固定，则可能的query位串是一个有限集合Q，归一化max与分母也来自有限数值集合F。是否能为所有可能的未来query和归一化结果同时维护历史摘要，从而避免保存无界append-only KV？

## 左折叠参考核的候选恒等式

假设score是固定纯位函数s(q,k)，位级运算及每次舍入明确。已加入历史(k_j,v_j)，不滑动删除；无另依赖未编码绝对位置的score。对每个q维护历史max M_q。对每个(q,m)维护：

Z[q,m] = fold_add_j exp_b(s(q,k_j)−m)。

对每个(q,m,z,通道r)维护：

O[q,m,z,r] = fold_add_j mul_b(div_b(exp_b(s(q,k_j)−m),z),v_jr)。

所有fold沿原时间顺序左折叠、同primitive及舍入。候选查询为：

m=M_q；z=Z[q,m]；output_r=O[q,m,z,r]。

即使m,z依赖整个历史，它们最终也在我们枚举的有限集合中。若每次append为所有参数组合按同一顺序更新，上式有一个可归纳证明的机会。对不可能的m/z组合，需将除零/溢出等totalize为带错误标记的有限状态，不能在counterfactual更新中让整个程序提前抛异常。

## 若成立，可能的收益与严格限制

- 对固定b、d，表项数有限且与历史长度无关；但约为|Q|·|F|²·d，通常对模型宽度/精度指数巨大。绝不能冒称实际200B可用或保持小常数时间。
- 它不是有限提示答案查表：历史长度可无界，摘要按token更新；但仍必须说明按模型规模计算的成本是否让“足够解决”失去实用意义。
- 仅对应明确左折叠核。平衡/分块归约树不等价；可以研究为每组参数维护二进制块森林、用O(log n)栈保持一个预先定义的前缀兼容归约树，但不能自动推广到任意GPU归约。
- 只有append-only KV直接适用。滑动删除的非结合fold通常不能逆向消去；变长窗口可能仍需要O(C)存储。
- 位置相关score必须已经通过有限query/key特征编码；动态重标度旧keys、未编码相对位置bias不自动包括。
- 因果固定层数的跨token归纳、输入/生成协议、采样顺序和资源异常还需另证。全序列双向attention不满足过去KV不变的前提。

## 下一批次的可检验操作

1. 在很小的有限数值域（不是float32全域）实现上述摘要，与保存完整历史的字面参考逐前缀、逐query比较；包括非结合饱和加法和无效分母状态。
2. 完整证明左折叠引理，或找一个counterexample；不要只靠测试。
3. 评估前缀兼容平衡树是否可用O(log n)空间精确保持，给出具体树定义。
4. 将算法成本同时写成输入长度n与模型参数b,d的函数；不能只把指数模型常数藏进O(1)。

本候选的新鲜度高于继续更改已有门控自指；尚未有正式证明/独立复核，不构成原标准P/NP或人类覆盖结论。
