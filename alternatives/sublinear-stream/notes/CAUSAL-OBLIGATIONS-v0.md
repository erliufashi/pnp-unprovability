# 完整因果策略组合的补充义务（未认证）

供下一批次审计，不能合并进已证M14或现有T3。

1. 增量reference与从头batch重算是不同规格。即使未来位置mask为0，总shape改变也可能重排过去归约；要么证明实际prefix-stability，要么明确reference本来就是旧KV冻结的增量程序。
2. 多层归纳需外层token位置、内层层/头。q/k/v及post-map都必须从已经匹配的当前前层hidden与计费位置特征计算，不能把它们作为外部求解oracle给出。
3. 处理一个新token期间，不同层/头的缓存计数暂时不同，不能把所有层的shape一概视为同一时刻。每头存自己的O(log t)计数或用明确阶段指针区分新旧shape；固定层/头数下仍为O(log t)，但须计费。
4. 位置函数可输出有限word，却可能使用无限地址/高代价计算；应要求其O(log t)空间及多项式时间。动态重标旧key、未编码相对距离、无限非均匀位置表不免费包含。
5. 固定数值前向无随机内部节点时，最终采样可用同一内核/随机位耦合；若内部随机调用与执行顺序有关，必须另证，不因输出“看起来差不多”就算等价。
6. 生成D(n)需有多项式界，输出回读只经已计费的token反馈；停止/长度/预算计数及错误返回语义明确。真实OOM或墙钟超时不从kernel功能等价自动转移。
7. 编译缓存总模型系数ΣK_layer,head可能对b/d指数大。理论上O(log t)内存与输入方向多项式，不等于实际200B/人类任务可用或模型规模多项式开销。

下一批次应先验证结构反例/契约，再给小多层模型逐步对照和完整归纳。旧证书不自动扩大。
