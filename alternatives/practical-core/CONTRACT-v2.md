# T3-v2 算法空间与六维可比性合同（CONTRACT-v2）

- **当前状态**：`UNRESOLVED`（形式化规范与局部边界已确立；完整同预算分离与现实分布覆盖尚未同时达成）
- **修订背景**：替代早期不准确的“无外部图灵机 200B LLM 参数量”代理（T3-v1，仅作历史条件性记录保留），将目标重定义为**架构无关、资源全额计费、能力保全的受限算法空间 $A_\Gamma$**。

---

## 1. 算法空间 $A_\Gamma$ 的结构与全成本账本

候选算法空间 $A_\Gamma$ 由固定输入/交互协议下的统一可执行程序构成，必须在评测前冻结数值/尺寸包络

$$
\Gamma = (w,\; B,\; F,\; M,\; S_{\text{persist}},\; Q_{\text{io}},\; \Sigma_{\text{resp}},\; H),
$$

各分量分别约束并独立记账（不同量纲保持向量，禁止无依据相加或用渐近 $O(\cdot)$ 吸收未付巨常数）：

1. **字宽与原语（$w$）**：固定字宽算术/位运算与明确地址范围；寄存器（如 16 个 $w$-bit 寄存器）、PC、阶段标志与燃料计数器全部计入动态配置位数（参见 `E-chief-dom-1`, `E-argon-FNS-audit1`）。
2. **描述与静态数据预算（$B$）**：程序代码与静态初始化常量总字节上限。若不设数值上限 $B$，任何线性时间类在固定有限任务宇宙 $\mathcal{U}$ 上都可硬编码真值表而产生“假收缩”；同样，不能用未固定指数的多项式并集（$\bigcup_k C_k = \mathrm{P}$）冒充严格收缩（参见 `C55`）。
3. **燃料 / 总步数（$F$）**：主控指令、输入获取/重读、初始化清零、随机数生成、子程序/工具内部计算与序列化通信的**累计总步数**。封闭可计算工具可以展开并入单一机器模型，但不得免除任何内部步数或持久状态（参见 `E52`, `C55`, `COMPOSITION-v1`）。
4. **瞬时工作空间（$M$）与同时存活峰值**：同一时刻同时存活的主控数组、候选缓冲、生成器/验证器未释放状态与反馈日志总量，不得简写为各模块峰值的 $\max$（参见 `E-argon-GVC-audit1`）。
5. **数据相关持久状态（$S_{\text{persist}}$）**：跨查询/跨轮保留的索引、缓存、数据特化编译代码或环境隐状态，必须与数据无关固定代码 $B$ 分开计入状态容量 $s$（参见 `ASTRA-E-PARITY-INDEX-1`, `B56`, `D-GVC-STATE-1`）。
6. **输入访问与响应字母表（$Q_{\text{io}}, \Sigma_{\text{resp}}$）**：明确区分明文位/字随机读取、顺序扫描、可写原位修改（mutable input 属于计费可变状态，见 `ASTRA-B-MUTABLE-1`）与受限黑盒查询；外部工具或验证器的每次返回位宽 $\log_2|\Sigma_{\text{resp}}|$ 与批大小上限 $L$ 必须显式计费（参见 `OPAQUE-v2`, `ASTRA-F-OPAQUE-ALPHABET-1`, `D-GVC-BATCH-1`）。
7. **生命周期分母（$H$）**：明确区分冷启动 $T_{\text{cold}} = T_{\text{build}} + T_{\text{query},1}$ 与预声明有限查询次数 $H$ 下的摊销成本，严禁用虚构的 $H \to \infty$ 抹除预处理成本，且预处理 `Build` 对禁止读取的评测标签源必须满足非干涉性（参见 `E-argon-IDX-audit1`）。

## 2. 非确定性扩展 $ND_\Gamma$ 的公平对齐准则

若要在同一 $\Gamma$ 下声称确定性（或有界错误随机化）与非确定性严格分离（$D_\Gamma \subsetneq ND_\Gamma$ 或 $BPP_\Gamma \subsetneq ND_\Gamma$），两侧必须共享**完全相同的输入可见性、持久状态上限、工具/索引权限与总燃料 $F$**：

- **禁止免费只读长证书带**：双头单调只读证书配合 $O(\log n)$ 工作空间即可通过相邻计算行比对恢复整个 $\mathrm{NP}$（`E-chief-cert-1`, `C57`）。在亚线性工作空间下，非确定性猜测位必须通过逐位计费指令（如 `GUESSBIT`）生成，并存入与确定性侧同上限的计费寄存器/工作内存。
- **随机源真实可实现性**：在固定燃料下，公平随机位无法零误差生成奇素数域 $\mathbb{F}_p$ 上的精确均匀种子；必须使用显式二进抽样分布（计入一次总变差惩罚）或把拒绝采样超时显式计为失败分支（参见 `astra-argon` 二进种子审计与 `F-DYN-FP-1`）。

## 3. 六维可比性与 `INVALID_COMPARISON` 判定表

根据 `ASTRA-CHIEF-CONTRACT-MATRIX-1`，任何能力保全声明与分离下界若在以下任一维度失配，直接判定为 `INVALID_COMPARISON`：

| 维度 | 必须对齐的契约要素 | 已证伪的典型非法迁移反例 |
| :--- | :--- | :--- |
| **1. 输入可见性** | 明文位/字 vs 黑盒比较 `CMP` vs 预计算摘要 | 把 `CMP` 决策树下界 $\lceil\log_2(n!)\rceil$ 当作明文 RAM 下界（明文在 $M \ge \lceil 2^w/w\rceil$ 时可 $O(n)$ 直接寻址击穿，`ASTRA-CHIEF-CUTOFF-AUDIT-1`） |
| **2. 响应字母表** | 每次反馈位宽、候选批大小 $L$、是否返回见证 | 把二元相等查询的 $q/N$ 界套用于可返回多比特证书的黑盒接口（`ASTRA-F`）；把 $\log_2 m$ 轮二分下标误作恢复 $m$-bit 秘密（`GVC-audit1`） |
| **3. 持久状态** | 静态代码 $B$ vs 数据相关索引 $s$ vs 原数组副本 | 把静态 1-bit `OR` 摘要直接用于支持 $U$ 次 `SET` 更新的动态场景（实际需 $\ge \lceil\log_2(1+\sum_{k\le U}\binom{N}{k})\rceil$ bits，`B56`/`B57`） |
| **4. 生命周期** | 单次扫描 vs 多遍重读 vs 二阶段 `Build+Serve` | 用 $F=O(\log n)$ 亚线性探针分离 `OR`，却声称能包含需要 $7n+9$ 步的全输入 `SUM`（`A57`） |
| **5. 组合与历史** | 自适应历史条件核 $\varepsilon_i(h)$ vs 模块平均误差 | 单模块均匀 benchmark 误差仅 $1/m$，但合法公开边界路由在自适应工作流中错误率恒为 $1$（`COMPOSITION-v1`） |
| **6. 成功量词** | 全输入最坏情形 vs 均匀分布 vs 极小误差门槛 | 把 BSSV 要求 $\varepsilon \le (T/n)^{-\gamma(T/n)^2}$ 的分支程序下界直接当作常数错误率 $\varepsilon = 1/3$ 的 $BPP_\Gamma$ 下界（`E-argon-RAND-ED-2`） |

## 4. 当前候选评估与未决缺口

- **当前最接近全扫描能力底线的候选**：`E-argon-FNS-audit1` + `C62` 在 $\Gamma(n)=(w=\lceil\log_2(n^2+2)\rceil,\; F=32n+512,\; M=\lfloor\sqrt{n}\rfloor,\; B=4096)$ 下同时精确容纳全扫描 `SUM`/`DOT` 与非确定性 `ND_COLLISION`（$12w+21$ 步），并由 BSSV (JACM 2003, Thm 6.13) 排除渐近确定性 BRAM。
- **为何尚未达成 T3-v2**：
  1. `C62` 导出的无隐常数显式交叉维度高达 $n = 2^{3,315,164}$，远超物理与现实任务规模；
  2. 常数错误率 $\varepsilon = 1/3$ 的随机化全类下界（$BPP_{\text{BRAM}}(\Gamma)$）尚未闭合；
  3. 强参考解法组合 $B_*$ 的完整编译开销与现实任务分布覆盖数据仍未实测。
